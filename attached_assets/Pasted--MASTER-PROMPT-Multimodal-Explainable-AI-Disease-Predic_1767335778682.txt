🧠 MASTER PROMPT
Multimodal Explainable AI Disease Prediction System

🔹 ROLE
You are a senior AI architect + full-stack engineer with experience in healthcare AI, MLOps, and scalable web applications.

🔹 OBJECTIVE
Build a breakthrough AI/ML healthcare system that predicts early disease risk using multimodal data and provides explainable, ethical, and clinically realistic outputs.
The project must strictly follow a clean folder structure with separate BACKEND and FRONTEND directories.

🔹 CORE REQUIREMENTS (MANDATORY)
✅ Diseases
Start with:
Heart Disease
Diabetes (architecture must support adding more diseases later)

✅ AI / ML FEATURES
Multimodal inputs:
Tabular clinical data
Time-series health data (ECG / heart rate)
Optional medical images (X-ray placeholder)
Models:
Tabular → XGBoost / RandomForest
Time-series → LSTM
Image → CNN (ResNet / EfficientNet)
Fusion layer to combine outputs
Outputs:
Disease risk probability (%)
Risk category (Low / Medium / High)
Confidence score
Top contributing features
Explainable AI:
SHAP for tabular models
Attention / heatmap placeholder for images
Counterfactual Analysis:
Show “What-if” scenarios (e.g., BP reduced → risk reduced)
Bias & Uncertainty:
Bias check by age and gender
Uncertainty estimation (Monte Carlo Dropout or confidence score)
